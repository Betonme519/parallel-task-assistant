# 架构与实现

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `src/core/model.cjs` | 工作区校验与不可变命令操作：创建、记录、编辑、归档等 |
| `src/core/workflow.cjs` | 有序步骤、当前阶段、完成状态与步骤标识 |
| `src/main/store.cjs` | 串行写入、临时文件、备份恢复和撤销 |
| `src/main/index.cjs` | 窗口生命周期、IPC、截图导入、工作区导入导出 |
| `src/main/preload.cjs` | 向界面暴露有限的方法集合 |
| `src/main/dock.cjs` | 挂件与主页窗口几何、边缘激活区域 |
| `src/main/ai.cjs` | 视觉请求、有限重试和建议解析 |
| `src/main/credentials.cjs` | 环境变量读取与系统加密凭据保存 |
| `src/renderer/` | 任务面板、时间线挂件、表单和建议预览 |

## 流程计划与历史记录

每个任务包含 `workflow.steps` 和 `workflow.current`，分别表示有序阶段和当前索引；`nodes` 保存带时间的进展记录。计划描述未来的路径，节点描述已经记录的事实。完成最后一步会同步任务完成状态。旧任务允许没有流程计划，不会为它们凭空补造步骤。

## 一次写入

1. 界面通过 Preload 调用命令接口。
2. 主进程验证调用来源及相关参数。
3. 数据模型从现有状态生成下一份状态。
4. 保存队列写入临时文件，同步文件内容，保存上一份有效状态，再重命名临时文件。
5. 成功后更新内存状态和撤销历史，将结果返回界面。

失败不会先把内存状态推进到尚未成功保存的版本。正常退出等待保存队列完成。启动时主记录解析失败会尝试有效备份；无法恢复时停止启动。

这是面向单机个人工作区的实现，不能等同于数据库事务、跨进程锁或分布式一致性保障。备份不是无限版本历史，重要资料仍应定期导出。

## 桌面形态

挂件默认宽 280 逻辑像素，主页默认宽 448 逻辑像素；实际大小受显示器工作区域约束。挂件靠左右边缘放置，主进程检测边缘区域与指针位置，控制展开和收起。固定展开和编辑期间的保持状态避免操作中意外收起。

## 界面与系统能力

窗口启用 `contextIsolation` 和沙箱，关闭 `nodeIntegration`。主进程拒绝新窗口与页面导航，并检查 IPC 来源。Preload 仅暴露工作区、图片、AI、备份和窗口相关方法。

这些是当前实现中的防护措施，不代表已通过第三方安全审计。工作区文本与截图仍为本机可读数据。

## AI 路径

用户点击识别后，主进程读取选定截图，构造补充说明和所选任务的有限上下文，发送到固定视觉接口。输出解析后保留截图依据，将后续步骤标为建议。用户可以修改，最终显式保存。

无密钥时不发请求；认证失败不会重复重试；限流及部分服务端错误执行有限重试。系统提示与格式校验有助于约束输出，但不保证模型绝对正确，人工预览仍是流程的一部分。

`src/contracts.d.ts` 中保留了早期视觉接口草案；当前视觉请求及响应以 `src/main/ai.cjs`、主进程调用和对应测试为准，尚未将完整运行时代码纳入静态类型检查。

## 当前取舍

- 本地存储降低账户和服务依赖，同时不提供多设备同步。
- 手动推进支持不同类型的个人流程，同时无法自动获知外部事件。
- Electron 便于复用 Web 界面与桌面 API，同时带来完整运行时的体积成本。
- 当前主要验证 Windows 桌面路径，其他系统尚未作为发布目标。
