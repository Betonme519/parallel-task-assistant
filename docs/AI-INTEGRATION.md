# 语音与截图识别

## 交互流程

附图或粘贴截图 → 可选填写关注事项 → 识别并规划 → 预览依据和后续步骤 → 填入表单 → 编辑并保存。

识别结果不会自动写入任务。后续步骤统一视为建议；遇到歧义时请求补充说明。

## 实现与数据发送

当前源码使用 `glm-4.6v-flash`，固定端点为 `https://open.bigmodel.cn/api/paas/v4/chat/completions`。服务可用性及费用以服务商为准。

只有点击识别后才发起请求。请求包含当前截图、补充说明；更新任务时还包含所选任务的标题、当前步骤与流程步骤。不会自动上传整个工作区。

API 密钥可通过设置保存，或通过 `FLOWLINE_GLM_API_KEY` 环境变量提供；环境变量优先。保存使用 Electron `safeStorage`，系统加密不可用时拒绝保存。删除已保存密钥不会清除外部设置的环境变量。

## 语音

“语音输入”调起 Windows Win+H 听写，需系统麦克风及相关设置。Flowline 不保存音频；系统在线听写可能将语音交给系统服务处理。

## 验证范围

`npm test` 包含模型结果解析、歧义处理、建议标记、无密钥不发请求和有限重试测试。真实服务、麦克风、显示器与 DPI 组合需要独立验证。公开文档不附带个人真实识别记录。
